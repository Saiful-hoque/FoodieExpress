#  FoodieExpress — Modern Food Delivery Landing Page

A modern, highly responsive, and attractive landing page built for **FoodieExpress**, a fictional food delivery service, using **HTML5** and **Tailwind CSS**.

---

##  Key Features & Project Requirements

1. **Navbar**
   - Logo with custom branding: `FoodieExpress`.
   - Navigation Links: Home, Menu, About, Reviews, Contact.
   - Interactive "Order Now" CTA Button.
   - **Bonus**: Fully responsive mobile menu drawer toggle.

2. **Hero Section**
   - Catchy Heading: *"Delicious Food Delivered to Your Door"*.
   - Short engaging description and CTA button *"Explore Menu"*.
   - High-quality food imagery with subtle background glow effect.
   - Quick delivery stats (30 Min, 50+ Items, 4.9 Rating).

3. **Popular Dishes Section**
   - 3 Responsive Food Cards built with Tailwind Grid/Flexbox.
   - Includes Food Image, Name, Description, Rating, Price, and "Order Now" button.
   - **Bonus**: Category filter tabs (All, Burgers, Pizza, Drinks, Desserts).
   - **Bonus**: Promotional discount badges (*20% OFF*, *HOT SELLER*).

4. **Why Choose Us? (Benefits)**
   - Fast Delivery 
   - Fresh Ingredients 
   - Affordable Prices 
   - Designed with clean icons and hover micro-interactions.

5. **Special Offer Section**
   - Promotional Banner: *"Get 20% Off Your First Order!"*.
   - Promo code `FOODIE20` highlight with a "Claim Offer Now" button.

6. **Customer Reviews Section (Bonus)**
   - Rating stars, customer quotes, and user avatars.

7. **Footer**
   - Website name, copyright notice, contact details, and social media links (Facebook, Instagram).

---

##  Tech Stack & Design Principles

- **Framework**: HTML5 & Tailwind CSS (via CDN)
- **Typography**: Google Fonts (*Poppins*)
- **Breakpoints**: Full responsiveness across Mobile (`sm:`), Tablet (`md:`), and Desktop (`lg:`)
- **Effects**: Smooth transitions, hover scaling, shadow glows, and backdrop filters.

---

##  How to Run Locally

1. Download or clone this repository.
2. Open `index.html` directly in any web browser (Google Chrome, Edge, Firefox, Safari).
3. No build tools or Node.js environment required!
